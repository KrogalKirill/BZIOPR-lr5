# Поддержка принятия решений на основе метода Монте-Карло (GUI, Python)

Лабораторная работа №5 по курсу «Базы знаний и поддержка принятия решений».  
Проект реализует систему поддержки принятия решений для производственно-экономической задачи на основе имитационного моделирования методом Монте-Карло с псевдослучайными числами, генерируемыми сдвиговым регистром с линейной обратной связью (LFSR).

---

## 1. Постановка задачи (Вариант 6)

На предприятие поступает партия комплектующих изделий (резисторов) невысокой точности ($N = 10\,000$ шт.)[cite: 1].  
Требуется определить долю деталей ($P \in [0, 1]$ с шагом 5%), подвергаемых предварительному входному контролю, при которой суммарные издержки предприятия будут минимальными[cite: 1].

### Исходные параметры:
* **$A$ (доля бракованных резисторов):** $15\%$ ($p_{\text{def}} = 0.15$)[cite: 1]
* **$B$ (стоимость входного контроля одного резистора):** $7$ руб.[cite: 1]
* **$C$ (стоимость подгонки при выявлении брака на контроле):** $50$ руб.[cite: 1]
* **$D$ (стоимость замены бракованного резистора в готовом блоке):** $125$ руб.[cite: 1]
* **Генератор ПСЧ:** LFSR степени 32 по **полиному №15**[cite: 1]:
  $$X^{32} + X^{30} + X^{27} + X^{26} + X^{25} + X^{23} + X^{22} + X^{21} + X^{20} + X^{19} + X^{18} + X^{17} + X^{13} + X^6 + X^5 + X^4 + 1$$

---

## 2. Теоретическая модель

Математическое ожидание издержек на одно изделие при доле контроля $P$:
$$E(P) = P \cdot B + P \cdot A \cdot C + (1 - P) \cdot A \cdot D$$

Преобразуем выражение:
$$E(P) = A \cdot D + P \cdot [B + A \cdot (C - D)]$$

Подстановка параметров варианта:
$$E(P) = 0.15 \cdot 125 + P \cdot [7 + 0.15 \cdot (50 - 125)] = 18.75 - 4.25 \cdot P$$

Так как производная $E'(P) = -4.25 < 0$, функция монотонно убывает на всём отрезке $P \in [0, 1]$.  
**Теоретический оптимум:** $P = 100\%$ (сплошной входной контроль всех изделий). Метод Монте-Карло подтверждает этот результат статистически.

## 3. Архитектура проекта и принципы ООП

Проект спроектирован по принципам SOLID и разделения обязанностей (Separation of Concerns):

1. **`IRandomGenerator` (Interface):** Абстракция генератора случайных величин (Dependency Inversion). Даёт возможность подменять LFSR на другие генераторы без изменения логики симуляции.
2. **`LFSR32Generator`:** 32-битный генератор сдвигового регистра. Вычисляет бит обратной связи по четности битовой маски полинома №15[cite: 1] и нормализует значение в интервал $[0.0, 1.0)$.
3. **`VariantConfig` и `SimulationRow` (DTO):** Неизменяемые структуры данных (`dataclass(frozen=True)`), исключающие непреднамеренную мутацию состояния.
4. **`MonteCarloOptimizer`:** Изолированное математическое ядро, моделирующее независимые события $R_1$ (отбор на контроль) и $R_2$ (наличие скрытого брака)[cite: 1].
5. **`MonteCarloApp` (Presentation Layer):** Графический интерфейс на `CustomTkinter`. Вычисления вынесены в отдельный поток (`threading.Thread`), сохраняя отзывчивость GUI. Оптимальная стратегия подсвечивается зеленым цветом.

## 4. Установка и запуск

### Требования
* Python 3.9+
* Менеджер пакетов `pip`

### Шаги запуска

1. Клонировать репозиторий:
```bash
git clone [https://github.com/](https://github.com/)<ваш-аккаунт>/monte_carlo_decision_making.git
cd monte_carlo_decision_making
```

2. Создать и активировать виртуальное окружение:
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Запустить приложение:
```bash
python main.py
```
